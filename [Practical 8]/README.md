## 1. Aim
To interface and simulate five core sensors and actuators with the **Arduino Uno R3** in Tinkercad Circuits: an analog temperature sensor (TMP36), a potentiometer, a 16×2 I2C LCD display, a DC motor driven by an L293D H-Bridge IC, and a micro servo motor.
