## 1. Aim
To create and format a professional multi-page technical document in Microsoft Word using built-in styles, structured tables, captioned images, dynamic headers and footers, and automated references (Table of Contents, citations, and bibliography).

---

## 2. Theory

### 2.1 Document Styles & Automatic Table of Contents
**Styles** (found under the **Home** tab) apply consistent font families, sizes, colors, and paragraph spacing across an entire document:
- **Hierarchy Styles (`Title`, `Heading 1`, `Heading 2`, `Heading 3`):** Define structural levels for chapters and sections.
- **Body Styles (`Normal`, `Quote`, `List Paragraph`):** Maintain uniform line spacing (e.g., `1.15` or `1.5`) and paragraph margins.
- **Automated Navigation:** Applying `Heading 1` and `Heading 2` styles enables Word's **Navigation Pane** and allows one-click generation of an auto-updating **Table of Contents (TOC)** from the **References** tab.

### 2.2 Structured Tables
Tables organize comparative or technical data cleanly inside a document:
- **Table Design & Layout:** Customizing cell padding, borders, alternating row shading, and column widths prevents text crowding.
- **Header Row Repeat:** Enabling **Repeat Header Rows** under **Table Tools → Layout** ensures column headers automatically reappear if a table spans across a page break.

### 2.3 Images, Text Wrapping & Captions
Visual figures enhance technical readability when anchored properly:
- **Text Wrapping (`Square`, `Tight`, `In Line with Text`, `Top and Bottom`):** Controls how surrounding paragraphs flow around an inserted image.
- **Captions & Cross-References:** Using **References → Insert Caption** adds numbered labels (e.g., *Figure 1*, *Table 1*) that automatically renumber if figures are added or reordered, and enables dynamic **Cross-References** inside the text.

### 2.4 Headers, Footers & Page Numbering
- **Headers & Footers:** Repeat document metadata—such as report title, subject code, or author name—in the top and bottom margins of every page.
- **Section Breaks & Different First Page:** Enabling **Different First Page** keeps the cover page clean while starting **Page Numbering** (`Page X of Y`) from the introduction onward.

### 2.5 References, Citations & Bibliography
Microsoft Word's **References** tab automates academic citation management:
- **Insert Citation & Manage Sources:** Stores source metadata (books, journals, websites) in a reusable source manager.
- **Citation Styles & Bibliography:** Formats in-text citations and generates a complete **Bibliography / Works Cited** section in standard formats (APA, IEEE, MLA).
- **Footnotes & Endnotes:** Adds explanatory notes at the bottom of a page or the end of the document.

## 3. Steps for Implementation
1. Open Microsoft Word, create a new blank document, and configure standard page margins (`1 inch` on all sides) and line spacing (`1.15`).
2. Create a cover page using the **Title** and **Subtitle** styles, followed by a **Page Break** (`Ctrl + Enter`).
3. Structure the main report into sections and subsections using **Heading 1** and **Heading 2** styles, and insert an automatic **Table of Contents** on Page 2 via **References → Table of Contents**.
4. Insert a formatted comparison table (**Insert → Table**), apply header row shading, adjust cell alignment/padding, and enable **Repeat Header Rows**.
5. Insert a relevant technical diagram (**Insert → Pictures**), set text wrapping to **Top and Bottom**, and attach a numbered label using **References → Insert Caption** (*Figure 1*).
6. Double-click the top and bottom page margins to configure a custom **Header** (document title) and **Footer** (dynamic page numbers), enabling **Different First Page** so the cover page remains unnumbered.
7. Add two academic sources via **References → Insert Citation** (IEEE/APA style), insert a footnote, and generate a formatted **Bibliography** at the end of the document.
8. Save the file as `formatted_document.docx` and export a copy as `formatted_document.pdf` (plus a screenshot `output.png`) for previewing on GitHub.
